**Ember Court — Duel of the Four Winds.** A complete single-player card duel in the browser: you face Sable, the Storm Warden, in simultaneous-reveal rounds. Ember burns Gale, Gale wears down Stone, Stone dams Tide, Tide douses Ember — element advantage adds +3 power. Mend heals, Ward blocks, Siphon steals life, and winning two rounds in a row arms your next card with Momentum (+2). First to 0 life loses; Sable's favoured element is telegraphed, and every 4th round you scout one of its cards. Title screen, live table with both hands, readable values and suits, score and life totals, win and loss screens, keyboard (1–5) and mouse play, and WebAudio sound effects — all static files, no network.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Click **Play the Duel**, then click a card (or press 1–5) each round.
